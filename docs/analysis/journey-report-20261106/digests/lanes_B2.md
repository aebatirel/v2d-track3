## Lessons

- **Pre-registered rules caught false signals, but single seeds still fooled the lane.** Realistic masses looked harmful on one seed (ep2 0.944 to 0.736), then "signal" on three seeds (0.738 to 0.898). The G3 final then showed ep2 collapsing again (0.736 to 0.584), which makes the mean -0.034 (my arithmetic) and a harm verdict. ep2 is a recurrent collapse case: needs at least two seeds before any adoption.
- **Reference build variance dominates the seed signal.** Seeds on one reference agreed to 0.001; references built on different boxes differed by up to 0.31. Build a reference per seed, or read results per reference.
- **Single noisy replays mislead.** Jitter means over 8 to 64 copies are needed: ep2's grasp-lock reference scored 0.141 on one replay and 0.260 +/- 0.071 on average.
- **Check confounds before crediting a gain.** Physics fit v1 gained only by shifting frame 0, which the scorer aligns on. Option 3's ep2 gain came from a first-round checkpoint before any solver change.
- **Verify claims across sessions.** A 6 mm cavity error on eval 10 was wrong; the real cause was a 5 mm pose error, found by another session. A grasp tool silently used the robot hand for a human-hand test, voiding three runs.
- **Ledger and budget.** A $25 top-up appeared five times in the spend ledger; one $3.88 run was counted twice. Running totals were inflated; the Vast credit itself was unaffected (per the summary).
- **Operations.** The lane hit repeated 5-hour usage limits (30 Oct 10:20, 11:48, 15:14, 15:51, 20:40, 21:24 UTC; 31 Oct 01:11 and 06:51 to 07:21 UTC), interrupting turns. Watchers were restarted several times; log watches time out after 30 minutes.
- **Costs in summaries.** Measured box costs stated: G1 $1.29; G2+G3 $6.48; mass-check $9.10; S1 $3.31 (estimated from run time); option 3 about $6.8 (estimate). Vast credit moved from $16.17 (31 Oct 04:47) to $128.43 (10:57). Credit was $114.27 at 16:17.
