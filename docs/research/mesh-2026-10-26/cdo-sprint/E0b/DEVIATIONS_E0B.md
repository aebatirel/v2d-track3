# E0b (eval build): implementation details and interpretations of C0b PREREG sections 9-10

Written 2026-10-31 ~20:45 UTC, before any E0b eval candidate exists (the only eval runs before this file are the
local dry run of `jobs/e0b_box.sh` on eval 8 + 10 at stride 8, a code test whose outputs are discarded). Each item is
a detail the PREREG left open; none changes a pre-registered value, candidate set, pick rule or threshold. The public
stage's D1-D10 (`../C0b/DEVIATIONS_PUBLIC.md`) apply unchanged, because the eval job runs the same helpers
(`c0b_obs.sh`, `c0b_prep.py` commands, `c0b_check.py`, `c0b_fetch.py`, the `c0b_tasks.py` build lines).
